# 🔤 Missão das Letras

Jogo educativo desenvolvido para auxiliar no acompanhamento e desenvolvimento de habilidades de alfabetização e matemática.

#### Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- Express

#### Estrutura do projeto

```text
Missao-das-Letras/
├── src/
├── public/
├── server/
│   └── server.js
├── package.json
├── package-lock.json
├── vite.config.ts
├── index.html
└── README.md
```

#### Clonar projeto
```
git clone https://github.com/analuuvk-creator/missaoDasLetras.git
```
```
cd Missao-das-Letras
```
```
npm install
```

#### Iniciar o servidor Express
```
node server/server.js
```

#### Iniciar o servidor Vite
```
npm run dev
```

#### Descobrir o IP do computador principal
```
ipconfig
```

#### Acessar pelo outro computador
```
http://10.137.11.203:8443
```
